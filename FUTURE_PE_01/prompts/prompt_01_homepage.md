# Prompt 01 — Homepage Copy

## Prompt

```
You are an expert web copywriter specializing in conversion-focused tourism content.

CLIENT:
- Name: Afriroad Travel & Tours
- Type: Local tourism agency — Lome, Togo
- Specialty: Discovery of Togo's natural, cultural and human treasures

VISUAL IDENTITY:
- Logo: Map of Africa with a golden winding road
- Colors: Forest Green #2A7A2A + Gold #F5A800 + White
- Spirit: Adventure, African authenticity, discovery

TARGET AUDIENCE:
- Local and international tourists
- Togolese diaspora
- Families and school groups
- Travelers seeking authentic experiences

Generate the complete homepage copy including:
1. A compelling H1 headline with a clear value proposition
2. A subtitle (who it's for + main benefit)
3. A short inspiring introduction (3-4 sentences max)
4. 3 key strengths (short title + 2-sentence description each)
5. An emotional and motivating closing statement

Tone: Warm, adventurous, proud of African heritage.
Goal: Make the visitor want to discover Togo and contact the agency immediately.
```

## Prompt Logic

| Element | Why It's Included |
|---------|------------------|
| Client briefing | Grounds the AI in a real business context |
| Visual identity | Ensures brand-consistent language and spirit |
| Target audience | Forces audience-specific, non-generic messaging |
| 5 numbered output blocks | Produces structured, immediately usable content |
| Tone instruction | Avoids generic AI-sounding text |
| Goal statement | Keeps the AI focused on conversion |
