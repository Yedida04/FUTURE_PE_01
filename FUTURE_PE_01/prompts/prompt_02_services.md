# Prompt 02 — Services Page Copy

## Prompt

```
You are a web copywriter specializing in African tourism.

CLIENT:
- Name: Afriroad Travel & Tours — Lome, Togo
- Colors: Green #2A7A2A and Gold #F5A800
- Specialty: Local tourism, nature and culture in Togo

Generate descriptions for 4 main services:
1. Nature Tours (Kpime waterfalls, Missahohe forest, Mount Agou)
2. Cultural Circuits (Tamberma villages, Lome market, voodoo)
3. Custom Travel (groups, families, diaspora)
4. Transfers & travel logistics in Togo

For each service include:
- Service name (H2)
- Client-benefit focused description (2-3 sentences)
- 3 included elements (bullet points)
- 1 "Why choose Afriroad" closing sentence

Tone: Adventurous, reassuring, authentically African.
```

## Prompt Logic

| Element | Why It's Included |
|---------|------------------|
| Real Togolese locations | Adds authenticity and local credibility |
| Benefit-focused description | Speaks to what the client gains, not just features |
| Bullet points (3 per service) | Scannable format, ideal for web pages |
| "Why Afriroad" sentence | Differentiates the agency from competitors |
