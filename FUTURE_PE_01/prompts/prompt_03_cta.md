# Prompt 03 — Call-to-Action Sections

## Prompt

```
You are a conversion copywriting expert for the tourism sector.

CLIENT:
- Name: Afriroad Travel & Tours — Lome, Togo
- Colors: Green #2A7A2A and Gold #F5A800

Generate 3 distinct Call-to-Action sections:

CTA 1 — Main Booking
Goal: Push visitor to book or request a quote
Include: inspiring title, 2 motivating sentences, 2 button texts

CTA 2 — Trust & Testimonials
Goal: Reassure a hesitant traveler
Include: 1 credible number (travelers served),
2 realistic fictional testimonials,
3 agency commitment points

CTA 3 — Local Urgency
Goal: Target residents living in Togo
Include: reference to undiscovered Togolese treasures,
free consultation offer, 2 button texts

Tone: Warm, emotional, action-oriented.
```

## Prompt Logic

| Element | Why It's Included |
|---------|------------------|
| 3 separate CTAs | Each targets a different visitor psychology |
| CTA 1 — urgency | Converts visitors who are already interested |
| CTA 2 — social proof | Converts hesitant visitors with trust signals |
| CTA 3 — local belonging | Targets an underserved local audience segment |
| Dual buttons per CTA | Gives visitors two low-friction action options |
